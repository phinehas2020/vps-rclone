# VPS Live Files

Public application information and privacy policy for Phinehas Adams’s private rclone Google Drive integration.

- Homepage: https://phinehas2020.github.io/vps-rclone/
- Privacy policy: https://phinehas2020.github.io/vps-rclone/privacy.html
- Google OAuth authorized domain: `phinehas2020.github.io`

GitHub Pages publishes the root of the `main` branch. The site uses static HTML and CSS with no build step or external scripts.

This repository is for public documentation only. OAuth client JSON, rclone configuration, tokens, server logs, and application data must stay out of it.
