Privacy policy

Private rclone integration

Google Drive for live application files.

VPS Live Files connects Google Drive to a virtual private server through rclone, so selected applications can store and retrieve their files using the operator’s Drive storage.

Operated by Phinehas Adams for private infrastructure use.

What the application does

The integration manages application files and attachments in Google Drive and uses a temporary local cache for file access. Databases, operating system files, and application services remain on the server.

Google authorization is used to create, read, update, and delete files accessible to this application. The integration requests the limited drive.file permission.

Your files stay private

Access is used only to provide the operator’s file storage integration. Drive data is never sold or used for advertising or AI model training. This public information site does not receive OAuth tokens or display stored application files.
