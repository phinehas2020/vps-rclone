VPS Live Files

Privacy policy

Effective October 1, 2026

VPS Live Files is a private Google Drive integration operated by Phinehas Adams. It uses rclone to provide storage for selected live application files on the operator’s virtual private server. This policy covers that integration and this public information website.

Google data accessed

The application requests https://www.googleapis.com/auth/drive.file. This permission limits access to files created by the application or files explicitly opened or shared with it. Within that access, the application can read file contents and metadata such as names, identifiers, sizes, folder relationships, and modification times, and can create, update, download, or delete files as required by the connected applications.

Google supplies OAuth access and refresh tokens after authorization. The integration does not collect the Google account password.

How data is used

File contents and metadata are used only to store, retrieve, synchronize, and manage the operator’s application files. OAuth tokens maintain the authorized connection to Drive. Operational logs may include file names, synchronization status, and errors needed to operate and troubleshoot the integration.

Google user data is not sold, used for advertising, or used to develop or train AI or machine learning models.

Storage and protection

Application files are stored in the authorized Google Drive account. Files may also be held in a temporary cache on the operator’s server. OAuth credentials and token configuration are stored on the server with filesystem access restricted to its administrator. Connections to Google’s APIs use HTTPS.

The public GitHub repository and website contain only informational pages. They do not contain OAuth credentials, access tokens, or stored application files.

Data sharing

Data is processed by Google Drive, the operator’s server hosting provider, and the applications the operator connects to this storage. The integration does not make Drive files public or share them with unrelated third parties. Disclosure may occur if required by applicable law.

This website is hosted by GitHub Pages. GitHub may process website request information under its privacy statement. This site adds no analytics, advertising scripts, or cookies.

Retention, deletion, and revoking access

Files remain in Drive until the operator or a connected application deletes them. Local caches and operational logs are retained as needed for file access and troubleshooting; the server administrator can remove them. Copies and backups maintained by connected applications have their own retention settings.

The account owner can revoke this application’s access in Google Account connections. Revoking access prevents further access through the revoked authorization; it does not automatically delete existing Drive files, caches, logs, or backups. To remove integration data, stop the integration, revoke authorization, and have the server administrator remove its tokens, caches, and logs. Delete unwanted Drive files and any separately maintained copies through their respective applications.

Google API Limited Use

VPS Live Files’ use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and policy changes

For questions or deletion assistance, contact Phinehas Adams through the project’s GitHub issues. Please do not include private data or credentials in a public issue. Updates to this policy will be published here with a revised effective date.
